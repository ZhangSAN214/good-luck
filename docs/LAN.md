# 在平板 / 手机上用圆桌（局域网访问）

阶段 35「本地部署」中的局域网部分（自启和备份还没做）。圆桌照旧跑在你的电脑上，数据只存在电脑上；平板只是在同一个 Wi-Fi 里打开电脑上的网页。不租服务器、不暴露到公网。

## 怎么用（第一次约 5 分钟）

1. **电脑上**：关掉正在运行的黑色服务窗口，双击项目根目录的 `start_lan.bat`（和 `start.bat` 一样会更新代码、安装、启动，只是多对家里的局域网开放）。
2. 第一次这样启动时，Windows 可能弹窗问「是否允许 Python 访问网络」：**只勾「专用网络」**，点允许。
3. 网页顶部点「**平板**」：设一个访问口令（至少 6 位），下面会列出平板该打开的地址，例如 `http://192.168.1.23:8000`。
4. **平板上**：在同一个 Wi-Fi 里，用 Safari / Chrome 打开那个地址，输入口令；或者在电脑的「平板」面板里点「生成二维码」，用平板相机扫一下直接进入（10 分钟内有效、只能用一次）。
5. 添加到主屏幕：iPad 在 Safari 里点「分享」→「添加到主屏幕」；安卓在 Chrome 菜单里点「添加到主屏幕」。之后从桌面图标打开，全屏显示。

登录一次保持 30 天。改口令、或在「平板」面板里点「让所有平板退出登录」，所有平板都要重新登录。平板上顶栏的「平板」按钮变成「退出」。

平时不需要平板时，照旧双击 `start.bat`：只有这台电脑能打开。

## 平板打不开时

- **防火墙**：如果第 2 步点了拒绝，在**管理员 PowerShell** 里运行（「平板」面板里有同一条，端口按实际填好）：

  ```powershell
  New-NetFirewallRule -DisplayName "Roundtable LAN 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
  ```

  只放行「专用」网络的这一个端口。圆桌程序本身从不改系统设置。不用了可以删掉：`Remove-NetFirewallRule -DisplayName "Roundtable LAN 8000"`。
- **网络类型**：家里的 Wi-Fi 在 Windows 里要是「专用网络」（设置 → 网络和 Internet → Wi-Fi → 点当前网络 → 网络配置文件类型）。是「公用」时上面的规则不生效。
- **学校网络（eduroam）、咖啡馆、酒店**：这类网络通常隔离设备，平板连不到电脑；而且不可信，不要在这类网络下开放。离开家想用见下文「离开家里 Wi-Fi」。
- 地址变了：路由器重启后电脑的局域网地址可能会变，以「平板」面板里显示的为准（可在路由器里给电脑固定地址）。

## 安全设计

| 项 | 做法 |
|---|---|
| 默认 | 只监听本机；即使有人手动用 `--host 0.0.0.0` 启动，没开 `ROUNDTABLE_LAN=1` 时别的设备的请求一律 403 |
| 口令 | 只存加盐哈希（scrypt），文件 `data/lan_access.json`（不进 git）；不设口令平板就进不来 |
| 登录 | 带过期时间（30 天）的签名 cookie（HttpOnly、SameSite=Lax）；换口令或「让所有平板退出」即全部失效 |
| 输错 | 每台设备连续输错 5 次锁 60 秒，之后每次翻倍，最多 15 分钟 |
| 二维码 | 一次性配对码，10 分钟过期、用一次作废；只有电脑本机能生成 |
| 设置 | 设口令、生成二维码、让所有平板退出只能在电脑本机上做 |
| 其他 | 开放时只接受用 IP 或 localhost 打开（挡 DNS 重绑定）；本机不用登录 |

**限制**：家里局域网内是明文 HTTP，同一 Wi-Fi 里能抓包的人理论上能看到内容和登录 cookie，所以只在自己家等可信网络里开放。HTTP 下浏览器不允许 Service Worker，所以「添加到主屏幕」后是全屏网页，不能离线使用（反正数据在电脑上，电脑关着本来也用不了）。

## 离开家里 Wi-Fi 也想用（方案，等你点头再做）

推荐 **Tailscale**（私有组网，WireGuard 加密）：电脑和平板各装 Tailscale、登录同一个账号，两台设备之间就像在同一个局域网，平板用电脑的 Tailscale 地址（`100.x.y.z`）打开圆桌。不是公网隧道：别人扫不到、打不开，只有你账号里的设备能连。

| | Tailscale（推荐） | 公网隧道（Cloudflare Tunnel / ngrok 等） | 租服务器 |
|---|---|---|---|
| 谁能访问 | 只有你账号里的设备 | 任何知道网址的人（只靠口令挡） | 任何人 |
| 加密 | 端到端 WireGuard | HTTPS 到隧道商，隧道商能看到内容 | 自己配 |
| 数据位置 | 只在电脑上 | 只在电脑上，但流量过第三方 | 要搬到服务器，违背「只存本机」 |
| 花费 | 个人使用免费（额度以官网为准） | 免费档有限制 | 按月付费 |

**要做的改动（约 30～60 分钟）**：

1. 「平板」面板把 Tailscale 的 `100.x` 地址也列出来、能生成二维码（现在只列家用私有网段）。
2. 可选：只对 Tailscale 网卡开放，不对家里 Wi-Fi 开放（更收紧）。
3. 文档写清楚安装步骤。

**需要你在电脑和平板上做的（约 10 分钟）**：两边都装 Tailscale App 并用同一个账号登录（电脑上要管理员权限安装）。电脑必须开着、圆桌在运行、电脑没有睡眠。

**风险**：

- 要注册 Tailscale 账号（可用 Google / 微软 / GitHub 登录），设备列表存在 Tailscale 的协调服务器上（内容不经过它，只交换密钥和地址）。
- 平板丢了：在 Tailscale 后台把它移除，再在「平板」面板点「让所有平板退出登录」。
- 不要用 Tailscale 的 Funnel 功能（那是公网暴露）；也不用它的 Serve（经本机反向代理时，所有请求看起来都来自本机，会绕过登录）。
- 电脑睡眠或关机时平板打不开；要 24 小时可用需要改电源设置（不在这次范围）。
