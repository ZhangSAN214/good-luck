# 桌面版小人方案（只写方案，未实现）

目标：把网页里的小人放到桌面上，透明、无边框、始终置顶，像桌宠一样陪着，同时仍连着本机运行的圆桌服务。

## 选型：Tauri

- 体积小（几 MB），用系统 WebView，不带整套 Chromium；Windows 用户已有 WebView2。
- 透明窗口：`transparent: true`、`decorations: false`、`alwaysOnTop: true`、`skipTaskbar: true`、`shadow: false`。
- 现有网页小人（`web/js/agent/*`）原样复用：桌面版只加载 `http://127.0.0.1:8000/pet` 这类专用页面，不重写。
- 备选 Electron：生态成熟但体积大；只有 Tauri 的透明窗口遇到平台问题时才考虑。

## 要新增的部分

1. **专用页面 `/pet`**：只渲染小人和气泡，背景透明，无圆桌界面。数据仍走 `/api/members` 和 SSE，匿名未揭晓时的规则不变（没有成员信息就不显示）。
2. **窗口行为**：拖动用 Tauri 的窗口拖拽；点击穿透（透明区域不拦截鼠标，`setIgnoreCursorEvents` 按像素命中切换）；贴边吸附沿用网页逻辑。
3. **托盘**：显示 / 隐藏、选择陪伴的成员、退出。不做开机自启的默认开启（要用户自己勾选）。
4. **启动**：先检查本机服务是否在跑，不在就提示"请先启动圆桌"，不自己偷偷拉起后台进程。

## 不做

- 不收集使用习惯，不上传任何东西；位置和设置只存本机。
- 不做打卡、挽留、"想你了"之类制造依赖的提示（见 CLAUDE.md §5.1）。
- 不监控屏幕或其他应用窗口。

## 前置条件与风险

- 素材：至少一位成员的完整逐帧包（克劳德已有）。
- 鼠标点击穿透在不同系统上行为不一致，先在 Windows 验证，再看 macOS / Linux。
- 高分屏缩放：画布 1254×1254 需要按显示尺寸缩小，保持最近邻采样，避免像素糊掉。

## 里程碑（用户确认后再开工）

1. 最小窗口：加载 `/pet`，透明置顶，可拖动。
2. 点击穿透 + 托盘。
3. 打包（`.msi` / `.exe`），写安装说明。
