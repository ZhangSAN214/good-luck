# 桌面版小人方案（只写方案，本步不实现）

目标：小人不只在圆桌网页里，而是能飘在整个桌面上——透明背景、始终在最上层、可拖动、点穿透，和网页版共用同一套素材与状态机。对应路线图 v3.4/v4.0（R12），实现前需用户确认。

## 1. 选型：Tauri

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **Tauri**（Rust 壳 + 系统 WebView） | 安装包几 MB、内存小；原生支持透明窗口、置顶、无边框、点穿透；前端直接复用 `web/js/agent/` | 要装 Rust 工具链才能自己打包；Windows 依赖 WebView2（Win10/11 自带） | **选它** |
| Electron | 生态最成熟 | 安装包 100MB+，常驻内存大，为一个小人不划算 | 不选 |
| Python（PyQt/Tk） | 与后端同语言 | 要重写动画与状态机，透明和抗锯齿效果差 | 不选 |
| 纯浏览器 PWA | 零安装 | 网页做不到置顶和透明悬浮在桌面上 | 不选 |

## 2. 结构

```
圆桌后端（现有，Python/FastAPI，本机 127.0.0.1）
        ▲  HTTP / SSE（与网页相同的接口）
        │
桌面小人（Tauri）
  ├─ 一个透明、无边框、置顶、不在任务栏显示的窗口（约 256×256 + 气泡区域）
  ├─ 窗口里加载 web/pet.html（新增的精简页面，只含小人，不含圆桌界面）
  │    └─ 复用 web/js/agent/brain.js、pet.js、reactions.js、web/css/agent.css
  └─ 托盘图标：显示/隐藏小人、安静一会儿、打开圆桌网页、退出
```

- 不重写任何逻辑：状态机、反应、气泡、菜单、素材读取都是网页版的同一份代码。桌面版只提供「窗口壳」和少量系统能力。
- 小人窗口通过 `GET /api/members`（素材）与 SSE 事件流（讨论进度）和后端通信；后端没启动时小人安静待机，并在菜单里显示「圆桌没有运行」。
- 「跳到讨论」用系统默认浏览器打开圆桌网页对应会话。

## 3. 需要的后端 / 前端小改动（实现时再做）

1. 后端：提供「当前进行中的会话」的只读接口（会话 id、状态、是否匿名未揭晓），桌面小人据此订阅 SSE；已有的 `/api/sessions` 与事件流可能已足够，实现前先核对。
2. 前端：`web/pet.html` 精简页面——把 `app.js` 里创建小人的部分拆成可单独引用的模块；`pet.js` 的拖动改为调用 Tauri 的窗口移动（网页里仍用自己的 pointer 拖动）。
3. 贴边：网页版贴浏览器窗口边缘，桌面版贴屏幕边缘（用 Tauri 的 monitor 信息，多显示器时按小人所在屏幕计算）。

## 4. 桌面特有行为

- **透明与点穿透**：整个窗口透明；只有小人本身的像素区域响应鼠标，其余区域鼠标穿透到下面的软件（Tauri 的 `set_ignore_cursor_events` + 悬停检测）。气泡出现时临时扩大可点击区域。
- **置顶但不打扰**：始终置顶；全屏应用（视频、游戏、演示）时自动隐藏或躲到角落，退出全屏后回来。
- **启动**：开机自启动为可选项，默认关；随圆桌后端一起启动是第二个可选项（由 `update_and_start.bat` 之类的入口拉起），默认关。
- **位置记忆**：位置与是否隐藏存在 Tauri 的本地配置文件（与网页版的 `localStorage` 同样语义），读不到就用屏幕右下角。
- **系统通知**：只在「需要你确认」「讨论完成」两类重要事件弹系统通知，且遵守「安静一会儿」；其余仍然只靠气泡。
- **免打扰**：尊重系统勿扰模式和「安静一会儿」，不发声音。

## 5. 隐私与安全

- 只连本机 `127.0.0.1` 的圆桌后端，不联网、不上传任何东西，没有任何 key；Tauri 的权限清单（capabilities）只开：窗口控制、托盘、打开外部链接、本地配置读写。
- 匿名会话未揭晓时的规则与网页版一致：**小人整个移除**，窗口里没有图片和素材地址（直接复用同一段判断，并加桌面版测试）。
- 小人不读屏幕、不读剪贴板、不读其他软件的内容，也不做「主动观察用户」之类的功能。
- 遵守产品原则：坦诚是 AI、不制造依赖（不做「你好久没来了」的挽留提醒）。

## 6. 打包与分发

- 开发：`npm`/`cargo` 工具链 + `tauri dev`；发布：`tauri build` 出 Windows 安装包（`.msi`/`.exe`），macOS/Linux 以后再说。
- 素材不进安装包：仍然读用户本机的 `data/avatars/roundtable_assets/`（路径在配置里可改）。
- 签名：个人自用先不签名，首次运行会有 SmartScreen 提示，需要用户点「仍要运行」。

## 7. 分步实施建议（每步一个路线图条目）

1. 把网页里的小人拆成可复用模块 + `web/pet.html`（纯前端，可在浏览器里先看效果，有测试）。
2. 新建 `desktop/`：Tauri 工程，透明置顶窗口加载 `pet.html`，能拖动、能点穿透。
3. 托盘菜单、位置记忆、全屏躲避。
4. 系统通知、开机自启动选项、打包脚本。
