# 小人差分素材清单

给每位成员各做一套动作帧和表情帧，放进本机素材目录（`data/avatars/roundtable_assets/`，不进 git）。
没有的动作 / 表情不会报错，网页小人会回退为程序动画；**只有 `idle`（待机）是必需的**。
做完后运行 `python scripts/check_pet_assets.py --write` 检查并生成 `pet.json`。

## 1. 统一规格（所有成员相同）

| 项目 | 要求 |
|---|---|
| 画布 | 512×512 像素（已验收的克劳德素材就是 512），所有帧同一尺寸；脚本默认 512，`--size` 可改 |
| 背景 | 真透明（PNG 带 alpha，或 WebP）；四个角必须全透明，不能带白底或棋盘格 |
| 锚点 | 脚底（站立姿势）贴近画布底边正中，脚底离底边 ≤ 12% 画布高；水平居中偏差 ≤ 15% |
| 留白 | 角色不要碰到画布四边（碰到会被提醒可能被裁切）；跳、庆祝等离地动作可以悬空 |
| 风格 | 像素风，与该成员 `chibi_transparent` 同一造型、同一配色；边缘保持硬边，不要抗锯齿渐变、不要半透明光晕 |
| 光照 | 不画投影（网页里小人自带阴影），不画文字和气泡 |
| 文件大小 | 每帧建议 ≤ 300KB |
| 格式 | 推荐 PNG；也支持 WebP（需带透明）；JPG 不行（没有透明） |

## 2. 文件夹与命名

```
<素材目录>/<成员 id>/
  idle/00.png 01.png …          动作：文件夹名就是动作名
  wave/00.png …
  face/happy/00.png …           表情：face/<表情名>/
  face/sad/00.png …
  pet.json                      脚本生成，不用手写
```

- 成员 id 与 `members.json` 里的 `id` 一致。
- 帧文件名是两位（或三位）数字，从 `00` 开始连续，不能跳号；每个动作 / 表情最多 64 帧。
- 文件夹名不是下面清单里的名字，会被忽略并提醒。

## 3. 每位成员要做的动作

「最少」是脚本提醒的下限，「推荐」是效果比较顺的帧数；帧率和是否循环由脚本写进 `pet.json`。

| 动作（文件夹名） | 含义 | 最少 | 推荐 | 帧率 | 循环 | 画法要点 |
|---|---|---|---|---|---|---|
| `idle` | 待机呼吸（**必需**） | 2 | 4 | 4 | 是 | 身体微微起伏，首尾帧能接上 |
| `blink` | 眨眼 | 2 | 3 | 12 | 否 | 睁→半闭→闭，只改眼睛 |
| `walk` | 走动 | 4 | 6 | 8 | 是 | 朝右走（网页会按方向镜像），首尾帧接上 |
| `jump` | 跳 | 3 | 5 | 10 | 否 | 下蹲→起跳→最高→下落 |
| `wave` | 挥手 | 3 | 6 | 8 | 否 | 抬手→左右摆→放下，用于「需要你确认」 |
| `think` | 思考 | 2 | 4 | 4 | 是 | 歪头、手托下巴或抬手摸脸 |
| `talk` | 说话 | 2 | 4 | 8 | 是 | 嘴一张一合，身体轻微点头 |
| `type` | 打字 | 2 | 4 | 8 | 是 | 面前有小键盘或本子，手交替动 |
| `celebrate` | 庆祝 | 4 | 6 | 10 | 否 | 双手举起、跳起、撒花 |
| `sleepy` | 犯困 | 2 | 3 | 3 | 是 | 眼皮打架、点头 |
| `sleep` | 睡着 | 2 | 4 | 2 | 是 | 闭眼、趴下或坐着睡，呼吸起伏 |
| `drag` | 被拖起挣扎 | 2 | 3 | 8 | 是 | 被提起来，手脚乱蹬（脚不用贴底） |
| `land` | 落地 | 2 | 3 | 12 | 否 | 落地压扁再弹回站姿 |
| `talk_book` | 说话时书角强调（专属，可选） | 2 | 3 | 6 | 否 | 克劳德用；其他成员按各自道具自定 |
| `letter` | 特殊待机：写信（专属，可选） | 2 | 6 | 3 | 是 | 一直循环到下一次活动 |
| `gift` | 彩蛋：收到来信（专属，可选） | 2 | 6 | 2 | 否 | 末帧停留见 `pet.json` 的 `hold_last_s` |
| `curtsy` | 被摸头行礼（专属，可选） | 2 | 4 | 3 | 否 | |
| `flip` | 翻书思考（专属，可选） | 2 | 4 | 3 | 是 | |
| `bookface` | 书盖脸（专属，可选） | 2 | 4 | 3 | 是 | |

## 4. 每位成员要做的表情

表情帧是**只换脸**的整张小人图（身体站姿同 `idle` 第一帧），每个表情做 1 帧即可，也可以做 2～3 帧让表情有小变化。

| 表情（文件夹名） | 含义 | 画法要点 |
|---|---|---|
| `happy` | 开心 | 眯眼笑、嘴角上扬 |
| `smug` | 得意 | 半眯眼、嘴角一边翘 |
| `thinking` | 思考 | 眼睛看向斜上方，嘴小小的 |
| `surprised` | 惊讶 | 眼睛睁大、嘴张成圆形 |
| `confused` | 困惑 | 眉毛一高一低，嘴歪 |
| `shy` | 害羞 | 脸红、眼睛躲开 |
| `angry` | 生气 | 眉毛下压、鼓腮 |
| `sad` | 难过 | 眉毛八字、眼角有泪 |
| `sleepy` | 困 | 眼皮半垂、嘴小小打哈欠 |

## 5. 成员清单（逐位打勾）

成员 id 以你本机 `members.json` 为准。每位成员复制下面这张表，做完一项在「完成」列打勾：

| 类别 | 项目 | 完成 |
|---|---|---|
| 动作 | idle / blink / walk / jump / wave / think / talk / type / celebrate / sleepy / sleep / drag / land（共 13 个） | ☐ |
| 表情 | happy / smug / thinking / surprised / confused / shy / angry / sad / sleepy（共 9 个） | ☐ |
| 检查 | `python scripts/check_pet_assets.py --member <成员 id> --write` 显示「结果：通过」 | ☐ |

按推荐帧数算，一位成员约 55 张动作帧 + 9～18 张表情帧。**先做 `idle`、`talk`、`think`、`wave`、`celebrate` 和 `happy`、`thinking`、`confused`，这几个最常用**，其余可以以后补。

## 6. 可直接复制的改图提示词

把该成员的 `chibi_transparent` 作为参考图一起发给图像模型。把方括号里的内容换掉。

### 6.1 动作帧（每次生成一整排，再切成单帧）

```
参考图是我的像素风小人 [成员名]。请严格保持造型、配色、画风、像素粗细、头身比和画布比例完全不变，只改动作。
生成 [N] 帧连续动画，动作是：[动作描述，例如“向右走路，左右脚交替，身体轻微上下起伏”]。
要求：
- 每帧 512×512 像素，背景完全透明，不要任何背景、地面、阴影、文字或气泡。
- 所有帧里角色大小一致，站立时脚底在画布底边正中，不要平移整个角色。
- 帧与帧之间只有动作的小变化，首尾帧能接上（循环动作）。
- 像素风硬边，不要抗锯齿渐变，不要加新的配饰或改变发型衣服。
按从左到右的顺序排成一行输出。
```

### 6.2 表情帧

```
参考图是我的像素风小人 [成员名]。请严格保持造型、配色、画风、像素粗细和站姿完全不变，只改脸部表情。
表情：[表情描述，例如“开心：眯眼笑，嘴角上扬”]。
要求：256×256 像素，背景完全透明，不要加文字、符号或气泡；身体和头发的位置与参考图完全一致，只有眼睛、眉毛、嘴和脸红可以变化。
```

### 6.3 逐项动作描述（可直接填进 6.1）

- idle：站立，胸口和肩膀微微上下起伏，身体其余保持不动，4 帧循环。
- blink：站立不动，眼睛睁开→半闭→完全闭上，3 帧。
- walk：向右走路，左右脚交替迈步，手臂前后摆，身体上下起伏，6 帧循环。
- jump：下蹲蓄力→离地起跳→最高点（双脚离地、手臂上扬）→下落，5 帧。
- wave：抬起右手，在头旁左右摆动，另一只手自然下垂，面带微笑，6 帧。
- think：歪头，一只手托着下巴，眼睛看向斜上方，轻微晃动，4 帧循环。
- talk：嘴巴一张一合，头轻轻点动，手自然下垂，4 帧循环。
- type：面前有一个小键盘，双手交替敲击，低头看键盘，4 帧循环。
- celebrate：双手举过头顶欢呼，跳起一次，周围不加彩纸（彩纸网页里自带），6 帧。
- sleepy：眼皮半垂，头一点一点地往下沉，3 帧循环。
- sleep：闭眼，坐着或趴下睡觉，身体缓慢起伏，4 帧循环。
- drag：被一只看不见的手从头顶提起，双脚悬空乱蹬，表情惊慌，3 帧循环。
- land：落地瞬间身体压扁→回弹→站直，3 帧。

## 7. 做完之后

1. 把切好的单帧按第 2 节放进成员文件夹。
2. `python scripts/check_pet_assets.py`：先只看报告，把「错误」改完（尺寸、透明、命名问题），「提醒」可以以后再处理。
3. `python scripts/check_pet_assets.py --write`：检查通过的成员会写出 `pet.json`。
4. 刷新网页，双击小人播放全部动作 / 表情的演示，肉眼检查每一个。

## 8. 出图流程补充（ChatGPT 分窗口、对齐、Gemini 草稿）

素材由用户在 ChatGPT 网页生成（额度共用，一天约 30 张，一位成员一天；一个对话一次最多 10 张），不进 git。

**一天四个窗口**（每个窗口先附该成员立绘作为参考图，再发 6.1 / 6.2 的提示词）：
- 窗口 A：idle、blink、wave、talk
- 窗口 B：think、type、sleepy、sleep
- 窗口 C：celebrate、drag、land、walk、jump
- 窗口 D：该成员专属动作和表情

**注意**：整图重画时每一张都以参考图为准、不要基于上一张画，否则造型会漂；待机类动作要写明「只改胸口起伏和发梢」。

**收到图之后**
1. 解压后用 `pose_process.py --base 立绘.png --src 解压目录 --out 输出目录 --align`（在用户的 `_brief` 目录里）：色板吸附、透明度二值化、脚底和水平对齐。
2. 切成单帧，按第 2 节放进成员文件夹，再按第 7 节检查并生成 `pet.json`。
3. 专属的特殊待机、彩蛋（`special_idle` / `easter_eggs`）按 `docs/tracks/agent.md` 手写进 `pet.json`，脚本不生成。

**用 Gemini 出草稿（可选，会花钱）**
`python scripts/gen_pet_frames.py --ref 立绘.png --member whale --action sign --frame "k0=…" --frame "k1=…" --out 草稿目录 --max-usd 0.5`
走 OpenRouter 的 Gemini 图像模型（`models.yaml` 里 `gemini-3.1-flash-image`，约 0.067 美元 / 张），每个 `--frame` 出一张，已存在的跳过，累计费用到上限就停。只是草稿，像素颗粒、色板、画布尺寸不保证和立绘一致，先出一张看效果；之后仍要走 `pose_process.py` 和 `check_pet_assets.py`。
