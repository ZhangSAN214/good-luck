# 小人差分素材清单（R4）

每位成员一套。克劳德已验收；其余 7 位（小白龙、鲸鱼娘、歌若柯、千问、双子星、Kimi、GLM）按本清单做。图由用户在 ChatGPT 生成（额度共用，一天一位，约 30 张），本仓库只放检查脚本和文档，**素材不进 git**（放 `data/avatars/`）。

## 规格

| 项 | 要求 |
|---|---|
| 画布 | 1254×1254，RGBA PNG，背景透明 |
| 透明度 | 只有 0 或 255，不要半透明边缘 |
| 锚点 | 脚底固定在画布高度约 92%（允许 ±3%），水平居中 |
| 像素风 | 色板只用立绘颜色；约 10 像素的块状颗粒；不加平滑渐变 |
| 造型 | 服装、发型、配饰、比例与立绘一致，只改姿势或表情 |
| 命名 | 动作帧 `成员_动作_k0.png`、`k1`…（序号从 0 连续）；表情 `成员_face_表情.png`；成员前缀用小写英文，如 `whale` |

## 动作与帧数

必须的动作缺了检查不通过；可选的缺了只警告（程序会用代码动画顶上）。

| 动作 | 最少帧 | 默认 fps | 循环 | 必须 | 备注 |
|---|---|---|---|---|---|
| idle | 3 | 3 | 是 | 是 | 只改胸口起伏和一小撮发梢/尾巴，其余像素不变 |
| wave | 4 | 6 | 否 | 是 | |
| talk | 3 | 6 | 是 | 是 | |
| think | 4 | 4 | 是 | 是 | |
| type | 3 | 6 | 是 | 是 | |
| sleepy | 4 | 3 | 否 | 是 | |
| celebrate | 4 | 8 | 否 | 是 | |
| drag | 3 | 6 | 是 | 是 | 脚离地，和待机有明显差异 |
| land | 3 | 8 | 否 | 是 | |
| walk | 4 | 8 | 是 | 否 | 鲸鱼娘 / 千问 / 双子星要做 |
| jump | 4 | 8 | 否 | 否 | 鲸鱼娘要做 |
| sleep | 3 | 3 | 是 | 否 | 小白龙 / Kimi / GLM 要做 |

表情（可选，每个一张脸部图层）：happy、smug、thinking、surprised、confused、shy、angry、sad、sleepy。

## 每天的分窗口（一个对话一次最多 10 张）

- 窗口 A：idle 3、wave 4、talk 3
- 窗口 B：think 4、type 3、sleepy 4
- 窗口 C：celebrate 4、drag 3、land 3
- 窗口 D：本成员专属动作（见 `给ChatGPT` 的成员指令）

## 可直接复制的改图提示词

开场（每个窗口先发一次，附立绘）：

> 这是像素风 Q 版角色（附图）。以后所有图以它为唯一准绳：造型、像素颗粒、配色都不要改，背景透明。全身关键姿势，1254×1254 透明 PNG，脚底固定在画布高度约 92%，只改姿势部位。色板只用母版颜色，透明度只能是 0 或 255，保持约 10 像素的块状颗粒，不加平滑渐变。每个动作 3～4 张关键姿势，命名"成员_动作_k0.png、成员_动作_k1.png"，不要画中间帧。每张都基于附图母版重新画，不要基于上一张画。动作幅度要清楚：对照待机，脚、手臂、重心要有明显变化。现在直接开始，不要再询问。

单个动作（把方括号换掉）：

> 保持造型不变，只改动作：[动作]，共 [N] 张，[一句话描述，如"右手举过头顶左右挥动"]。命名 [成员]_[动作]_k0.png 起。

单个表情：

> 保持造型不变，只改表情：[表情]。只出脸部图层（其余透明），命名 [成员]_face_[表情].png。

## 收到图之后

1. `pose_process.py --base 立绘.png --src 解压目录 --out 输出目录 --align`：色板吸附、透明度二值化、脚底和水平对齐（用户的 `_brief` 目录里）。
2. `python scripts/check_pet_art.py <输出目录> --member whale`：检查尺寸、透明、脚底、命名、帧数，列出问题。
3. 无错误后加 `--write` 生成 `pet.json`；在 `members.json` 的 `images.pet` 指向它。
4. 专属的特殊待机、彩蛋（`special_idle` / `easter_eggs`）按 `docs/tracks/agent.md` 手写进 `pet.json`，脚本不生成。

## 用 Gemini 出草稿（可选，会花钱）

`python scripts/gen_pet_frames.py --ref 立绘.png --member whale --action sign --frame "k0=…" --frame "k1=…" --out 草稿目录 --max-usd 0.5`

走 OpenRouter 的 Gemini 图像模型（`models.yaml` 里 `gemini-3.1-flash-image`，约 0.067 美元 / 张），以立绘为参考图，每个 `--frame` 出一张；已存在的跳过，累计费用到上限就停。只是草稿：像素颗粒、色板、画布尺寸不保证和立绘一致，先只出一张看效果，再决定是否批量；之后仍要走 `pose_process.py` 和 `check_pet_art.py`。
