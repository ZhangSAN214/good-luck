# R1 头像接入（详细说明）

任务：把成员头像接入圆桌网页（讨论 / 协同的消息头像、圆桌座位、成员面板）。只做这一件事，做完推送，不合并。

一、准备（省 token：不要读 docs/PLAN.md；按 CLAUDE.md「必读索引」只读 docs/ARCHITECTURE.md 的 §2.6、§2.7）
- 分支：按 docs/ROADMAP.md 的「分支规则」，在 roadmap/auto 上做。
- 下面已经写明要改的位置，不需要通读代码库。

二、素材约定（素材在用户本机，不进 git，你的环境里没有；data/ 已在 .gitignore）
- 目录默认 `<项目根>/data/avatars/roundtable_assets/`，可用环境变量 `ROUNDTABLE_ASSETS_DIR` 覆盖。
- 入口 `members.json`：`{"version":2,"members":[{"id","name","vendor","nickname","theme_color","order","status","images":{...}}]}`。
  - images 的键：chibi、chibi_transparent、chibi_small、avatar、avatar_transparent、`avatar_circle_light`（{"256","128","64"}，推荐）、`avatar_circle`（{"256","128","64"}）。值是相对 members.json 的路径。
  - vendor 与 config/models.yaml 的 vendor 一致，用它把模型对应到成员。

三、要做的
1. 后端 core：新建 `src/roundtable/core/members_art.py`
   - 读取并校验 members.json（pydantic，容忍多余字段）；图片路径必须落在素材目录内（防路径穿越），文件不存在的图片记为 null；目录或 json 不存在 / 损坏时返回 available=false 与原因，**绝不报错**。
   - 按 vendor 建立「模型 id → 成员 id」（遍历配置里的模型）。**代码里不得出现任何具体厂商或模型名**（有架构测试）。
2. `core/runtime.py`：Runtime 加字段 `members_dir: Path | None`；`Runtime.build()` 加参数 `members_dir=None`，为空时取环境变量或默认目录（参照同文件 DB_ENV 的写法）。
3. `core/service.py`：加 `members()` 返回
   `{"available": bool, "reason": str|null, "members":[{"id","name","nickname","display"(nickname 或 name),"theme_color","order","status","images":{"avatar_64","avatar_128","avatar_256","chibi"}}], "models": {"<模型id>":"<成员id>"}}`
   图片 URL 形如 `/api/members/files/<相对路径>`，优先用 avatar_circle_light，没有就用 avatar_circle，chibi 用 chibi_transparent；不存在为 null。
   另加 `member_file(path) -> (bytes, mime)`：只允许素材目录内的 png / jpg / webp，否则 404。
4. `api/app.py`：加 `GET /api/members` 与 `GET /api/members/files/{path:path}`（响应头加 `X-Content-Type-Options: nosniff`、`Cache-Control: private, max-age=3600`），写在 "/" 静态挂载之前。
5. 前端：
   - `web/js/api.js` 加 `members()`；`web/js/app.js` 启动时请求一次，失败就当没有素材。
   - `web/js/view.js`：仿照文件里 `setKindLabels` 的写法加 `setMemberArt(data)`；修改 `Names.speaker()` 和 `avatar()`（约第 230～245 行）：**只有当 `this.model(...)` 返回了模型 id 时**（即匿名关闭或已揭晓），才按 models 映射查头像；有头像就渲染 `<img>`（128px 图，`alt` 为昵称，`loading="lazy"`，加载失败时移除 img 显示原来的单字），头像边框用 theme_color；没有就保持原来的单字圆形。不要改 view.js 其他部分。
   - `web/css/app.css`：`.av img{width:100%;height:100%;object-fit:cover;border-radius:inherit;display:block}`。
6. 匿名保护（最重要）：匿名开启且未揭晓的会话，页面上不得出现任何头像 img 或素材 URL。

四、测试（只用临时目录里生成的假 members.json 和 1×1 png，绝不提交真实图片）
- `tests/core/test_members_art.py`：正常读取、目录不存在、json 损坏、路径穿越被拒、缺图记 null、vendor 映射。
- `tests/api/test_members_api.py`：两个接口的返回格式、非法路径 404、没有素材时 available=false（参照 tests/api/test_app.py 的 client 写法）。
- `tests/web/` 加端到端：匿名会话没有头像 img；匿名关闭的会话显示头像 img。环境里有 /opt/pw-browsers/chromium 时先 `export ROUNDTABLE_CHROMIUM=/opt/pw-browsers/chromium`。
- 开发时只跑相关测试；提交前跑一次 `ruff check . && ruff format --check . && pytest -q`，必须全部通过。
