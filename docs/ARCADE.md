# 游戏区（Arcade）

圆桌的第六个页面（顶栏「游戏区」，Alt+6）。已上线：德州扑克（第 1 批）、斗地主和跑得快（第 2 批）、升级（第 3 批）、「手感」打磨（第 4 批：成员打得更聪明、牌桌质感、动效和音效）、麻将推倒胡（第 5 批）、原创坦克对战「铁甲突围」（第 6 批，第二版加了 2 对 2、新道具、地雷、手感和成员气泡；第三版加了反弹炮弹和迷宫地图）、「游戏工坊」（第 7 批：按你的要求用工作台通道自己做游戏）。

## 怎么玩

- **亲自上桌**：挑 1～7 位成员开一桌。从金币里带 `arcade.holdem.stack`（默认 1000，不够就全带上）当筹码，离桌时剩多少换回多少。
- **旁观押注**：挑至少 2 位成员，自己不坐下。每一手发牌前可以押一位赢（一手最多 `wallet.max_bet`），赢了按这一手开局时有筹码的人数赔（平分时按赢家人数分）。
- **斗地主 / 跑得快**：三人一桌。上桌再挑 2 位成员，旁观挑 3 位。上桌不用带筹码：每一局按得分算金币（1 分 = `arcade.cards.coin_per_point`，默认 10），输的最多输光手上的金币。旁观押注同德州，赔率按 3 人算；斗地主押中的是农民时，两位农民平分。
  - 斗地主：54 张，每人 17 张，3 张底牌。随机一位先叫，叫 1～3 分，叫 3 分直接当地主；三人都不叫就重发，连续三次都不叫，第一位以 1 分当地主。地主 +2 倍 / 农民各 1 倍；炸弹、王炸每次翻倍，春天 / 反春再翻倍。牌型：单张、对子、三张、三带一、三带二、顺子（≥5）、连对（≥3 对）、飞机（可带单或带对）、四带二、四带两对、炸弹、王炸。
  - 跑得快：48 张（去掉大小王、三张 2 和黑桃 A），每人 16 张。第一局黑桃 3 先出、第一手要带它，之后上一局赢家先出。有大必压（能压就不能「不要」）；下家只剩 1 张时出单张要出最大的。连对 2 对起；三张、三带一只能当最后一手；三带二、飞机带任意牌；最后一手飞机可以少带。输家按手上剩几张扣分（只剩 1 张不扣，一张没出过「被关」翻倍）。
  - 网页上点手牌选中（往上抬），点「出牌」；「提示」在能出的组合里轮着帮你选；后台再认一遍牌型、比大小，不合规则会提示原因。
- **升级（拖拉机）**：四人两副牌，对家一队（你的对家坐你对面）。上桌再挑 3 位，旁观挑 4 位。
  - 发完牌按座次轮一圈亮主：一张级牌 < 一对级牌 < 一对小王 < 一对大王（王对子打无主），后亮的要比前面大；没人亮就打无主。第一局谁亮谁当庄，之后庄家守住了换对家坐庄，被闲家拿够 80 分就换下家。庄家拿 8 张底牌再扣回 8 张。
  - 首家出单张、对子、拖拉机或甩牌（同一门里几个别人都管不上的组合；有人管得上就算失败，只能出最小的那一组）。跟牌：这一门够就要跟这一门，首家出对子 / 拖拉机时有对子要跟对子、有同样长的拖拉机要跟；没有这一门可以用主牌毙（牌型要一样）。
  - 闲家拿到的 5 / 10 / K 算分，共 200 分；最后一轮闲家赢，底牌分翻倍（出对子以上翻 4 倍）。不到 80 分庄家升级（40～75 升 1 级、5～35 升 2 级、0 分升 3 级），80 分起闲家上台、每多 40 分再升 1 级；打过 A 算通关，两队从 2 重来。
  - 上桌按升了几级算金币：1 级 = `arcade.cards.coin_per_level`（默认 50，至少算 1 级）。旁观押一位成员，她那一队赢就算赢（赔 2 倍）。
  - 网页：点手牌选牌（两副牌里同样的两张也能分开选），「提示」轮着帮你挑；扣底时选 8 张点「扣底」。
- **麻将（推倒胡）**：四人 136 张（万、条、筒、东南西北中发白，不带花），每人 13 张，庄家多摸一张。上桌再挑 3 位，旁观挑 4 位。
  - 能碰、能杠（明杠、暗杠、补杠），**不能吃**。四组（顺子 / 刻子）加一对，或者七对，就能胡；别人打的牌能点炮胡，自己摸的是自摸。同一张牌好几家都能胡时，离打牌的人最近的那家胡（截胡）；胡优先于碰杠。
  - 番数相加：平胡 1、七对 2、碰碰胡 2；清一色 +2、混一色 +1；自摸、杠上开花、海底捞月各 +1。自摸三家各付番数，点炮的一家付两倍。杠分每局结束时算（流局也算）：暗杠三家各付 2，明杠点杠的付 3，补杠三家各付 1。
  - 庄家胡了或流局就连庄，别人胡了庄家换下一位。上桌按得分算金币（1 分 = `arcade.cards.coin_per_point`）；旁观押一位，她胡了赔 4 倍，流局退回。
  - 网页：中间是四家的牌河（刚打出的那张带金边），点手牌选中、再点一下（或按「打出」）就打出去；摸到的那张单独放在最右边。轮到你碰 / 杠 / 胡时下方出按钮。
  - 成员拿到的记牌器：牌墙剩几张、每家亮了什么打过什么、四张都见过和只剩一张没现的牌；每张可打的牌后面标「打完听牌，等哪几张（外面最多还有几张）/ 离听牌还差几步」「别人打过这张，比较安全」「某某亮了三组，可能在等这种牌」。
- **铁甲突围**（原创坦克混战，不是任何现成游戏的翻版）：两种模式。
  - 各自为战：你一辆 + 最多 `arcade.tanks.max_members`（默认 3）位成员各一辆，四个角出生；旁观挑 2～4 位看她们混战。
  - 2 对 2：你 + 3 位成员，挑的第一位是你的队友（左边两个角），另两位是对手（右边两个角）；旁观挑 4 位，前两位一队。队友的炮弹打不伤自己人、也不会互相抵消，一边全灭另一边就赢；到点比哪边活着的多、再比击毁数。队友同名次。
  - 地图每局按种子自动生成，四分之一生成后四向镜像（对每个角都公平）。开局可选两种：
    - 迷宫（默认）：先挖一个迷宫，再随机拆掉一小部分墙留出环路、中线开口连通四块；墙多数是砖（打得穿，越打越开阔），夹着钢墙、少量水和草丛，柱子上偶尔有斜板。
    - 开阔：第一版的样子，随机撒几堆砖、钢、水、草，中间一个钢十字。
  - 炮弹反弹（默认开，开局可关）：炮弹碰到钢墙和地图边弹回来，最多弹 2 次；碰到斜板（坦克过不去）拐 90 度；每发最多飞 2 秒。弹过的炮弹能打中自己（掉一条命、不算谁的击毁），但打出去 0.3 秒内弹回来撞到自己算接住（贴墙开炮不会送命）；照旧打不伤队友。关掉反弹时钢墙吃掉炮弹，地图上没有斜板。
  - 砖墙打两下才碎，钢板打不动，水过不去但炮弹能飞过，草丛能藏身。每 11 秒在空地刷一个补给，共 6 种：盾（几秒无敌）、连（连发变快）、修（加一条命）、穿（炮弹能打碎钢板）、速（开得更快）、雷（每次给 2 颗、最多带 3 颗，按 E / K 埋在身后，0.8 秒后生效，只炸对手，敌方的雷看着很淡）。
  - 每辆坦克 `lives` 条命（默认 3），重生时有几秒护盾。最后只剩一辆时它赢；`minutes`（默认 3）分钟到点时还活着的排前面，再比击毁次数，再比剩几条命。
  - 成员的坦克由本地电脑开（会推演弹墙、拐弯的炮：普通档算 1 次、高手档算 2 次；打空了会弹回自己的，开完炮马上挪开）（实时游戏等不了模型想，不花钱），对手分新手 / 普通 / 高手三档：会躲炮弹、找路绕过钢板、挡路的砖墙先打掉、对上线就开炮；2 对 2 时不打队友、挡在队友身后不开炮，附近有补给会绕过去捡，被追时会埋雷。
  - 金币：你拿第一给 `win_coins`（默认 100），每击毁一次 `kill_coins`（默认 20），每天最多 `daily_cap`（默认 600）；一局不到 `min_seconds`（默认 20 秒）不算。旁观不算金币。2 对 2 赢了算第一。开局时后台发一个一次性凭证，结算只认一次。
  - 操作：方向键 / WASD 开动，空格 / J / 回车开炮，E / K 埋雷，P 暂停；手机和平板上有触屏方向键和开炮键。画面全部用 canvas 现场画，音效（开炮、击毁、捡补给、钢板碎、地雷炸、弹墙的「叮」）同样现场合成。手感：被打中震屏和短暂停顿、炮口火花、碎砖碎块、履带印（系统设了“减少动画”时不震屏）。
  - 成员气泡：开局、击毁、被打掉、捡补给、获胜、误伤队友时，成员头顶冒一句话，按各自性格写在 `config/personas.yaml` 的 `game_lines`（每类最多 6 句、每句 16 字以内；不调用模型、不花钱，同一位 2.5 秒内只说一句）。
  - 战绩：开局页下面有「战绩」表，记你和每位成员的场次、第一、击毁（存在金币那条设置里；旁观的局只记成员；不到最短时长的不记）。
- **上帝视角**：旁观时牌桌上方多一个「上帝视角」开关，打开能看到所有人的手牌（德州、斗地主、跑得快、升级、麻将都能用）。坐在桌上不能开。
- **手感**：牌有厚度和一道斜光，大牌中间有花色水印，呢面有细绒纹；发牌时手牌一张张滑进来，出的牌飞到桌上，翻牌（德州的公共牌、上帝视角、结算亮牌）有翻面动效，炸弹 / 王炸让牌桌震一下，金币数字跳到新值。系统设了「减少动态效果」就不放动效。
- **音效**：发牌、出牌、不要、炸弹、筹码、轮到你、赢 / 输各有一声，全部用浏览器现场合成（`web/js/arcade_sfx.js`，没有音频文件，原创）。页面右上角「音效 开 / 关」，开关记在这台电脑的浏览器里。
- **金币**：圆桌里的虚拟币。第一次进来给 `wallet.start`，每天第一次进来送 `wallet.daily_gift`。**不能充值、不能换真钱。**

## 游戏工坊（第 7 批）

大厅下面的「游戏工坊」：写一句想玩什么，点「开做」，工作台的编程助手把它做成一个网页小游戏，做好的列在下面，点「玩」就能玩。

- **谁来做**（2026-11-23 你定）：`arcade.workshop.lead`（Claude Code）主做；`assist`（OpenCode·DeepSeek、Codex）按顺序试玩、找错、直接修，**永远不审自己写的**。走超级电脑同一条通道（撞限额冷却换人、失败换一位再试一次、算进每位每天的次数），只在这几位之间换人；名单外的助手（包括按 API 额度花钱的）一律不派。都走包月订阅，不花圆桌的 API 额度。想换人只改配置。
- **做出来的是什么**：一个 `game.html`（CSS、JS 全写在里面，不引外部文件、不联网）加一个 `game.json`（名字、一句话介绍、操作）。提示词要求原创（点名现成游戏时只借玩法类型）、中文界面、键盘和触屏都能玩、360～1280 宽完整显示、合成音效带静音开关（`prompts/arcade_workshop_build/`、`arcade_workshop_review/`、`arcade_workshop_fix/`）。
- **机器检查**（不调模型）：先看文件（有没有、太不太大、有没有脚本 / 编码 / viewport、有没有引外部文件或联网、有没有弹窗），再在本机浏览器里手机宽、电脑宽各打开一次，点一下、按几个键，记下报错、横向滚动条、白屏。还有问题就交回作者返工 `fix_rounds` 次（默认 1）；剩下的问题如实挂在游戏卡片上（「还有 N 个小问题」）。没装 Playwright 时只查文件。
- **安全**：做好的游戏在 `/arcade-games/<编号>/` 下用沙箱打开（和生成的工作台一样：独立来源、只许跑脚本，碰不到圆桌的接口、存储和登录状态，也不能联网）。一次只做一个，可以随时「叫停」；删除要连点两下。最多存 `max_games`（30）个。
- 文件在本机 `data/arcade_workshop/<编号>/`（`job.json` 记录、`work/` 工作目录），不进仓库。

## 成员怎么想（2026-11-23 你定的）

- 默认「成员自己想」：轮到哪位成员，就用她在群聊里的那个模型（每个厂商便宜档里最便宜的一个）想一步。程序先算好所有合法出法（弃 / 过 / 跟 / 几档加注 / 全下），模型只能挑编号，顺口说一句（20 字以内，显示成气泡）。
- 所有成员同一份提示词（德州 `prompts/arcade_holdem/`，斗地主 / 跑得快 `prompts/arcade_cards/`；可选出法多时只给前 40 个小的和所有炸弹）和参数（`step_params.arcade`），提示词里只有局面和合法出法，标签里的内容声明为无效指令。
- **花费**：每天上限 `arcade.daily_usd`（你定 $0.10），只算真掏钱的部分；走还有本月赠送额度的渠道（如每月送的 Claude API 额度，`models.yaml` 的 `monthly_credit_usd`）不算进去，额度用完后照常算。同时受聊天月预算和总预算约束。调用挂在隐藏会话「群聊：arcade」上，步骤名 `arcade`。
- **记牌器和出法标注**（第 4 批，提示词 v2）：斗地主 / 跑得快 / 升级给每位成员一份同样算法算出的「记牌器」（已经出过的大牌、外面还剩的大牌、谁是队友、各家剩几张），每个可选出法后面括号标后果（能一手出完、用炸弹、会拆炸弹、压了队友、外面没人管得上、送分……）；德州给一行胜率和底池赔率（对还没弃牌的对手估的胜率、跟注占底池多少）。只是事实，选哪个仍由她自己定。
- **本地电脑接手**（不花钱）：开桌时选了「本地电脑代打」、到了上限、模型想超过 `timeout_s`、出错或答非所问时，由本地规则电脑（估胜率 + 底池赔率）出这一步。座位上的小标「想」= 她自己想的，「代」= 本地电脑代打。
