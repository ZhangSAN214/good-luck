# 游戏区（Arcade）

圆桌的第六个页面（顶栏「游戏区」，Alt+6）。已上线：德州扑克（第 1 批）、斗地主和跑得快（第 2 批）、升级（第 3 批）；之后是「手感」打磨（成员打得更聪明、牌桌质感和音效），再依次是、麻将、原创坦克对战「铁甲突围」，最后是「游戏工坊」（按你的要求用工作台通道自己做游戏）。

## 怎么玩

- **亲自上桌**：挑 1～7 位成员开一桌。从金币里带 `arcade.holdem.stack`（默认 1000，不够就全带上）当筹码，离桌时剩多少换回多少。
- **旁观押注**：挑至少 2 位成员，自己不坐下。每一手发牌前可以押一位赢（一手最多 `wallet.max_bet`），赢了按这一手开局时有筹码的人数赔（平分时按赢家人数分）。
- **斗地主 / 跑得快**：三人一桌。上桌再挑 2 位成员，旁观挑 3 位。上桌不用带筹码：每一局按得分算金币（1 分 = `arcade.cards.coin_per_point`，默认 10），输的最多输光手上的金币。旁观押注同德州，赔率按 3 人算；斗地主押中的是农民时，两位农民平分。
  - 斗地主：54 张，每人 17 张，3 张底牌。随机一位先叫，叫 1～3 分，叫 3 分直接当地主；三人都不叫就重发，连续三次都不叫，第一位以 1 分当地主。地主 +2 倍 / 农民各 1 倍；炸弹、王炸每次翻倍，春天 / 反春再翻倍。牌型：单张、对子、三张、三带一、三带二、顺子（≥5）、连对（≥3 对）、飞机（可带单或带对）、四带二、四带两对、炸弹、王炸。
  - 跑得快：48 张（去掉大小王、三张 2 和黑桃 A），每人 16 张。第一局黑桃 3 先出、第一手要带它，之后上一局赢家先出。有大必压（能压就不能「不要」）；下家只剩 1 张时出单张要出最大的。连对 2 对起；三张、三带一只能当最后一手；三带二、飞机带任意牌；最后一手飞机可以少带。输家按手上剩几张扣分（只剩 1 张不扣，一张没出过「被关」翻倍）。
  - 网页上点手牌选中（往上抬），点「出牌」；「提示」在能出的组合里轮着帮你选；后台再认一遍牌型、比大小，不合规则会提示原因。
- **升级（拖拉机）**：四人两副牌，对家一队（你的对家坐你对面）。上桌再挑 3 位，旁观挑 4 位。
  - 发完牌按座次轮一圈亮主：一张级牌 < 一对级牌 < 一对小王 < 一对大王（王对子打无主），后亮的要比前面大；没人亮就打无主。第一局谁亮谁当庄，之后庄家守住了换对家坐庄，被闲家拿够 80 分就换下家。庄家拿 8 张底牌再扣回 8 张。
  - 首家出单张、对子、拖拉机或甩牌（同一门里几个别人都管不上的组合；有人管得上就算失败，只能出最小的那一组）。跟牌：这一门够就要跟这一门，首家出对子 / 拖拉机时有对子要跟对子、有同样长的拖拉机要跟；没有这一门可以用主牌毙（牌型要一样）。
  - 闲家拿到的 5 / 10 / K 算分，共 200 分；最后一轮闲家赢，底牌分翻倍（出对子以上翻 4 倍）。不到 80 分庄家升级（40～75 升 1 级、5～35 升 2 级、0 分升 3 级），80 分起闲家上台、每多 40 分再升 1 级；打过 A 算通关，两队从 2 重来。
  - 上桌按升了几级算金币：1 级 = `arcade.cards.coin_per_level`（默认 50，至少算 1 级）。旁观押一位成员，她那一队赢就算赢（赔 2 倍）。
  - 网页：点手牌选牌（两副牌里同样的两张也能分开选），「提示」轮着帮你挑；扣底时选 8 张点「扣底」。
- **上帝视角**：旁观时牌桌上方多一个「上帝视角」开关，打开能看到所有人的手牌（德州、斗地主、跑得快、升级都能用）。坐在桌上不能开。
- **金币**：圆桌里的虚拟币。第一次进来给 `wallet.start`，每天第一次进来送 `wallet.daily_gift`。**不能充值、不能换真钱。**

## 成员怎么想（2026-11-23 你定的）

- 默认「成员自己想」：轮到哪位成员，就用她在群聊里的那个模型（每个厂商便宜档里最便宜的一个）想一步。程序先算好所有合法出法（弃 / 过 / 跟 / 几档加注 / 全下），模型只能挑编号，顺口说一句（20 字以内，显示成气泡）。
- 所有成员同一份提示词（德州 `prompts/arcade_holdem/`，斗地主 / 跑得快 `prompts/arcade_cards/`；可选出法多时只给前 40 个小的和所有炸弹）和参数（`step_params.arcade`），提示词里只有局面和合法出法，标签里的内容声明为无效指令。
- **花费**：每天上限 `arcade.daily_usd`（你定 $0.10），只算真掏钱的部分；走还有本月赠送额度的渠道（如每月送的 Claude API 额度，`models.yaml` 的 `monthly_credit_usd`）不算进去，额度用完后照常算。同时受聊天月预算和总预算约束。调用挂在隐藏会话「群聊：arcade」上，步骤名 `arcade`。
- **本地电脑接手**（不花钱）：开桌时选了「本地电脑代打」、到了上限、模型想超过 `timeout_s`、出错或答非所问时，由本地规则电脑（估胜率 + 底池赔率）出这一步。座位上的小标「想」= 她自己想的，「代」= 本地电脑代打。

## 代码

| 位置 | 内容 |
|---|---|
| `core/arcade/cards.py` | 52 张牌、洗牌、中文写法 |
| `core/arcade/poker_eval.py` | 7 选 5 比牌（逐组合 / 快速两种算法，结果一致） |
| `core/arcade/holdem.py` | 无限注德州规则：盲注、下注轮、边池、全下发完、比牌；纯逻辑 |
| `core/arcade/holdem_bot.py` | 本地电脑对手 |
| `core/arcade/pattern.py` | 斗地主 / 跑得快的牌型：认牌型、比大小、从手牌里找能出的组合 |
| `core/arcade/shedding.py` | 斗地主、跑得快规则（叫分、出牌轮转、有大必压、报单、算分）；纯逻辑 |
| `core/arcade/shed_bot.py` | 斗地主 / 跑得快本地电脑对手 |
| `core/arcade/shengji.py`、`core/arcade/sj_bot.py` | 升级规则（亮主、扣底、跟牌、拖拉机、甩牌、算分升级）和它的本地电脑对手 |
| `core/arcade/hub.py` | 开桌 / 离桌、后台让成员一个个出、模型出牌与花费闸门、金币（`app_settings` 的 `arcade.wallet`）与押注 |
| `core/services/arcade.py`、`api/routes/arcade.py` | 接口 |
| `web/js/arcade.js`、`web/css/arcade.css` | 大厅、开桌、牌桌（牌面、牌背、筹码都是 CSS 自己画的） |

接口：`GET /api/arcade`（大厅：游戏、金币、今天花费、成员、当前牌桌）、`GET/POST/DELETE /api/arcade/table`（看 / 开 / 离桌）、`POST /api/arcade/table/act`（德州里你的动作）、`POST /api/arcade/table/play`（斗地主 / 跑得快里你叫分、不要、出牌：`{kind, cards, bid}`）、`POST /api/arcade/table/deal`（下一手，旁观时可带押注）、`PUT /api/arcade/table/think`（成员自己想 / 本地代打）、`PUT /api/arcade/table/god`（旁观的上帝视角）。

牌桌只放在内存里：关掉圆桌就散桌（筹码来不及退回的那一桌算丢了，见「已知不足」）。

## 已知不足

- 圆桌关掉或重启时，桌上的筹码不会自动退回金币（正常点「离桌」会退）。
- 成员说的话还没带上各自的人设口吻，只按名字说。
- 战绩（谁赢得多）还没有统计页。
- 斗地主 / 跑得快 / 升级的本地电脑对手只会基本打法（不记牌、不算牌），下一批「手感」改进。
