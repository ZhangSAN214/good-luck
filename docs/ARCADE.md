# 游戏区（Arcade）

圆桌的第六个页面（顶栏「游戏区」，Alt+6）。第一批：德州扑克；之后依次是斗地主、跑得快、升级、麻将、原创坦克对战「铁甲突围」，最后是「游戏工坊」（按你的要求用工作台通道自己做游戏）。

## 怎么玩

- **亲自上桌**：挑 1～7 位成员开一桌。从金币里带 `arcade.holdem.stack`（默认 1000，不够就全带上）当筹码，离桌时剩多少换回多少。
- **旁观押注**：挑至少 2 位成员，自己不坐下。每一手发牌前可以押一位赢（一手最多 `wallet.max_bet`），赢了按这一手开局时有筹码的人数赔（平分时按赢家人数分）。
- **金币**：圆桌里的虚拟币。第一次进来给 `wallet.start`，每天第一次进来送 `wallet.daily_gift`。**不能充值、不能换真钱。**

## 成员怎么想（2026-11-23 你定的）

- 默认「成员自己想」：轮到哪位成员，就用她在群聊里的那个模型（每个厂商便宜档里最便宜的一个）想一步。程序先算好所有合法出法（弃 / 过 / 跟 / 几档加注 / 全下），模型只能挑编号，顺口说一句（20 字以内，显示成气泡）。
- 所有成员同一份提示词（`prompts/arcade_holdem/`）和参数（`step_params.arcade`），提示词里只有局面和合法出法，标签里的内容声明为无效指令。
- **花费**：每天上限 `arcade.daily_usd`（你定 $0.10），只算真掏钱的部分；走还有本月赠送额度的渠道（如每月送的 Claude API 额度，`models.yaml` 的 `monthly_credit_usd`）不算进去，额度用完后照常算。同时受聊天月预算和总预算约束。调用挂在隐藏会话「群聊：arcade」上，步骤名 `arcade`。
- **本地电脑接手**（不花钱）：开桌时选了「本地电脑代打」、到了上限、模型想超过 `timeout_s`、出错或答非所问时，由本地规则电脑（估胜率 + 底池赔率）出这一步。座位上的小标「想」= 她自己想的，「代」= 本地电脑代打。

## 代码

| 位置 | 内容 |
|---|---|
| `core/arcade/cards.py` | 52 张牌、洗牌、中文写法 |
| `core/arcade/poker_eval.py` | 7 选 5 比牌（逐组合 / 快速两种算法，结果一致） |
| `core/arcade/holdem.py` | 无限注德州规则：盲注、下注轮、边池、全下发完、比牌；纯逻辑 |
| `core/arcade/holdem_bot.py` | 本地电脑对手 |
| `core/arcade/hub.py` | 开桌 / 离桌、后台让成员一个个出、模型出牌与花费闸门、金币（`app_settings` 的 `arcade.wallet`）与押注 |
| `core/services/arcade.py`、`api/routes/arcade.py` | 接口 |
| `web/js/arcade.js`、`web/css/arcade.css` | 大厅、开桌、牌桌（牌面、牌背、筹码都是 CSS 自己画的） |

接口：`GET /api/arcade`（大厅：游戏、金币、今天花费、成员、当前牌桌）、`GET/POST/DELETE /api/arcade/table`（看 / 开 / 离桌）、`POST /api/arcade/table/act`（你出牌）、`POST /api/arcade/table/deal`（下一手，旁观时可带押注）、`PUT /api/arcade/table/think`（成员自己想 / 本地代打）。

牌桌只放在内存里：关掉圆桌就散桌（筹码来不及退回的那一桌算丢了，见「已知不足」）。

## 已知不足（第 1 批）

- 圆桌关掉或重启时，桌上的筹码不会自动退回金币（正常点「离桌」会退）。
- 成员说的话还没带上各自的人设口吻，只按名字说。
- 战绩（谁赢得多）还没有统计页。
