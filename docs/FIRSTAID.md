# 出问题点这里：自检、体检报告、装后核对

圆桌出状况时一个入口查清楚。**只读，不改任何东西**；要恢复数据去「备份」，要撤销更新用 `undo_update.bat`。
思路学自 dsh-firstaid / dsh-butler-install 的说明（AGPL，只学思路，没有用它们的代码和文字）。

## 四类现场

| 现场 | 查什么 |
|---|---|
| 起不来 | 配置能不能读、key 填没填（只看有没有，不读内容）、数据库能不能打开、完整性、版本和程序是否对得上、磁盘空间、装后核对 |
| 卡住 / 没反应 | 后台任务（每天备份、成员生活、革新例会）是不是出错停了、模型渠道、预算是否用完、最近一天调用失败率、代码沙箱、dsh 工作台、数据库日志文件是否过大 |
| 想撤销刚才的更新 | 上次安全更新的结果（通过 / 自动退回 / 中途断了 / 撤销过），能不能撤销 |
| 数据不见了 | 有没有最近的备份；和最近一份备份比，作业、聊天、记忆、档案、朋友圈、生活记录是不是突然少了很多（少 20 条以上且一成以上才报） |

每项红（问题）黄（留意）灰（提示）绿（正常），红黄的带一句「怎么办」。

## 怎么用

- **网页**：顶栏「出问题点这里」→ 自动检查 → 点现场筛选 →「生成体检报告」→「复制报告」或「存成文件」。只能在电脑上用。
- **圆桌打不开时**：在项目目录运行
  ```bash
  roundtable doctor            # 离线自检：只读打开数据库，不做迁移
  roundtable doctor --report   # 输出体检报告
  roundtable doctor -o 报告.txt
  ```
  离线自检看不到后台任务、渠道、预算和调用记录（这些要服务开着）。有红色问题时退出码为 1。

## 体检报告

纯文本，只有检查结果：**不含聊天内容、记忆和 key**。生成时去掉所有已加载的 key 和疑似 key，用户目录换成 `~`。
可以整段复制发给我们。

## 装后核对

`start.bat`、`update_and_start.bat` 停掉旧服务后、启动前运行 `python scripts/install_check.py`，逐项核对是否真的装好
（不只看安装命令有没有报错）：Python 版本、是否在 `.venv` 里、圆桌是不是从这个项目目录加载（可编辑安装）、
`pyproject.toml` 的依赖是否都装上且版本对、数据目录能不能写、`.env` 在不在、配置能不能读、代码沙箱、8000 端口是否空着。
`python scripts/setup_dsh.py` 装完也核对（Node / npm / pnpm、运行时文件、运行时版本是不是钉死的那个、插件安装包哈希），
**没过就把运行时整批退回到装之前**（原来没有就删掉装了一半的）。`setup_dsh.py --check` 只核对。

结果写到 `data/install_check.json`（`start` / `update` / `dsh` 三节），自检页「起不来」里显示。核对没过只提示，照常启动。
