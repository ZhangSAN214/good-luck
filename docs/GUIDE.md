# 设置与新手指导

顶栏「设置」和每个页面第一次进入时的小卡片，代码在 `web/js/guide.js`、样式在 `web/css/guide.css`。纯前端，不调用模型、不花钱。

## 设置（一站式说明书）

- **常用工具**：顶栏装不下的小按钮（片头、外观、平板、游戏、备份、星图、上网）启动时原样搬进这里，按钮和原来的功能不变。「出问题点这里」和「一起看」留在顶栏：出问题时要一眼找到，投屏时要亮红点。搬进来的按钮有状态点时（游戏模式开着、有人在上网），顶栏「设置」也带一个绿点。
- **新手指导**：开关和「重新看一遍」。
- **功能说明书**：按终端、办公室、公寓楼、群聊、工作台、顶栏工具分组；每个功能一句话 + 两三步，「去打开」直接切页面、点按钮或打开对应面板。顶部能搜。

内容写在 `guide.js` 的 `FEATURES` 里。**新加功能时顺手在这里加一条**（名字、一句话、两三步、怎么打开），写大白话，不写任何模型、厂商或渠道名（架构测试会查）。

## 新手指导小卡片

- 第一次进某个页面时页面顶部居中弹一张，最多三句（`TIPS`）。
- 「知道了」：这一页以后不弹；没点就换了页也算看过。「不再提示」：全部关掉。
- 记录在浏览器 `localStorage` 的 `roundtable.guide`（`{off, seen}`），只在这台电脑上。
- 端到端测试默认把它关掉（`tests/web/conftest.py`），只有 `test_e2e_guide.py` 打开它测。
