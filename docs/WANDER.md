# 成员自己上网（第一期：只看）

方案：`/mnt/project-files/计划/成员虚拟手机电脑与投屏_方案.md` 功能一（2026-10-29 用户选「全按推荐」）。
你不投屏的时候，成员也能自己去逛小黑盒、B站、淘宝等网站，回来留下浏览记录和感想。

## 怎么逛

- **隔离浏览器**：在你电脑上用 Playwright 驱动自带的 Edge（没有就用 Chrome，再没有用 Playwright 的 Chromium），
  每位成员一个独立资料夹 `data/wander/<成员>/`（登录状态在里面，不进 git），和你自己的浏览器完全分开；默认在后台逛，不弹窗口（`headless`）。
- **一页一步**：程序取回页面文字和链接（不花钱）→ 交给成员（她自己的模型，`wander/v1` 提示词，所有成员同一套提示词和参数）
  → 她说一句感想、决定下一步：打开第几个链接 / 用搜索地址搜一个词 / 返回 / 结束（结束时写两三句小结）。
- **只看不动**：只按链接地址打开页面、按搜索地址模板搜索；不点按钮、不填表、不登录、不下载。
  链接列表只给白名单网站的；页面或内嵌框架跳去白名单以外的网站会被拦下（这一步算失败，她换个链接，出错页不读）。
- **同一时间只有一位在逛**（电脑内存有限）；每次最多 12 页、10 分钟，每看完一页停 4 秒，像人一样慢慢逛。

## 什么时候逛

- **自动**（`chat.wander.auto`）：在成员引擎的心跳上登记——醒着、闲着（看书 / 聊天 / 打游戏 / 看星星 / 待命）、
  10～23 点之间、今天还没逛过（每人每天最多 `trips_per_member_per_day` 次）、按 `trip_chance` 抽中时出门，网站随机挑。
  所有成员的规则完全相同，不看是哪个模型。
- **手动**：顶栏「上网」→ 选成员和网站（或「随她挑」）→「去逛逛」。

## 记录、记忆和花费

- 浏览记录存在隐藏会话 `wander:<成员>`（不出现在群聊列表、不能从群聊发言）：出门一行、每页一条感想（带网址和标题）、结束时一段小结和一行收尾（看了几页、花了多少）。
- 小结同时发感知事件 `perceive.web`（感知者 = 她自己），留给成员系统的记忆用。
- 花费记在这个隐藏会话上（step = `wander`），计入**生活每日上限**（`chat.life.daily_usd`，做这个功能时从 $0.10 调到 $0.15）、聊天月预算和总预算；每看一页之前都检查，不够就收尾。一次约 $0.01～0.05。
- 面板里的小图是她正在看的页面截图，只在内存里，不存盘。

中间是「让 X 去逛 Y」，下面是每位成员的浏览记录（最新的在上面）。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/wander` | 状态：能不能用、网站、正在逛的那位、每位成员今天逛了几次 |
| POST | `/api/wander/start` | `{member, site?}`，site 为空 = 随她挑 |
| POST | `/api/wander/stop` | 叫停（看完当前这页就收尾） |
| GET | `/api/wander/log?member=&after=` | 浏览记录 |
| GET | `/api/wander/frame` | 正在看的页面小图（JPEG；没人在逛时 204） |
