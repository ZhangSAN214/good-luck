# 大脑分区（2026-10-30，样本）

用户 2026-10-30 看完假模型 30 天模拟后说：第 1 天到第 30 天没有任何变化，交流机械、像在做任务，8 位成员说话没有特点。他希望成员**仅凭聊天和行为细节认不出是 AI**，有主观能动性、会自己成长、有深度，并提出仿照真实大脑做功能分区、各区联动。方案文档（Claude Doc）：「成员智能体 · 大脑分区方案」。

代码在 `src/roundtable/core/member/brain.py`，规则在 `config/roundtable.yaml` 的 `chat.engine.brain`。整个模块是程序计算，不调用模型；只用于生活群、私聊和成员之间的生活聊天，工作模式不挂载（`require_life`，办公室里的模型是电脑，群聊里的成员是人）。

## 为什么以前机械

1. 生活舞台是一张固定课表：`office/apartment.py` 的 `schedule()` 按成员 id 和钟点算出房间和活动，每周循环。
2. 成员没有「想要」：提示词最后一句都是「轮到你说话了」，生活聊天按 `turn % 人数` 轮流开口，心跳上只登记了上网一个模块。
3. 各个插件只交一行字：心情、关系拼进 600 字的上下文里，不改变成员的行为。
4. 慢变量太少，而且只会直线增长。
5. 说话的特点只靠提示词。假模型里 8 个人用同一张短语表，说话当然一模一样。

## 各区（这次样本做到哪）

| 区 | 管什么 | 代码 |
|---|---|---|
| 丘脑 | 一条消息对她有多显著：点名、你说的、她喜欢的东西、亲近的人、带情绪、问句 | `Brain.salience` |
| 下丘脑 | 驱力：想找人说话、闷了想换新鲜的、有话想说、想把手上的事往前推。随时间涨，涨速看性格分；被事满足就降 | `_grown` / `_satisfy` / `on_event`（订阅总线） |
| 前额叶·目标 | 从喜好里挑一两件「在做的事」，空闲时去做。会进步、会卡住，过坎时留下一件还没讲过的新鲜事 | `_goals` / `_pursue` |
| 前额叶·选择 | 空闲时段按驱力自己挑：练在做的事、找人、去新地方，或者照常 | `choose_activity`（生活排日程，先写内存，事情真发生了才落库） |
| 前额叶·意图 | 说话前按性格、心情、精力、驱力加权挑一个意图：接话、追问、讲自己的事、换话题、开玩笑、不同意、说心情、累了回短的；群里不显著又不想说就不接 | `Brain.intent` |
| 默认模式 | 走神：从喜好、旧记忆里冒出一个念头 | `thoughts` 里的 wander |
| 全局工作区 | 各区交上来的念头按强度加一点随机挑一件，写进意图卡；说完回传，讲过的新鲜事不再算新鲜 | `spotlight` / `after` |
| 海马、杏仁核、社会脑、语言区、睡眠 | 仍由原插件负责（P2 记忆、P3 状态、P4 关系、P5 说话、夜间整理），这里只读 | — |

生活聊天里由谁接下一句，看每个人的显著性和想说的劲儿，而不是轮流；大家都没什么想说的，这段聊天就自然收尾。提示词 `chat` v7、`chat_dm` v7、`life_chat` v4 新加了 `<intent>`，模型只负责把想法说出来。

状态存在 `app_settings` 的 `member_brain:<成员>`，不加迁移，只有本模块写。8 位成员用同一套规则，差别只来自各自的档案和经历。随机数由成员和时刻派生，结果可复现。

## 怎么验证

`roundtable sim` 的报告里新加了「大脑分区（主动性与变化）」一节：第一周和最后一周说的话重合多少、去处有几种，每位成员在做的事和进展、还没讲的新鲜事、最常挑的意图、最强的驱力。假模型现在照意图卡和说话习惯拼话，所以机制有没有起作用，不花钱也能看出来；像不像真人要用真模型看。

## 参考资料（只借思路，代码都是自己写的）

- Park 等《Generative Agents》（2023）：记忆流、反思、计划。→ 目标和日程，以及夜间整理的依据。
- Park 等《Generative Agent Simulations of 1,000 People》（2024）：人物资料越扎实，行为越像本人。→ 人物卡是一切差异的来源。
- Wang 等《Simulating Human-like Daily Activities with Desire-driven Autonomy》（ICLR 2025）：按多维欲望自己挑活动，比按任务驱动更像人、更多样。→ 下丘脑驱力和 `choose_activity`。
- Wang 等《Humanoid Agents》（EMNLP 2023 Demo）：基本需要、情绪、亲近度影响行为。→ 驱力、显著性里的亲近度。
- Croissant 等《Appraisal-Based Chain-of-Emotion》（2023）：先评价、再回应，更可信。→ 说话前先综合出意图卡。
- 《Sentipolis》（2026）：只靠提示词，智能体的情绪留不住（emotional amnesia）。→ 情绪和驱力由程序持续保存，不交给模型。
- 《Persistent Personas?》（EACL 2026）：长对话里人设会漂移。→ 风格和意图由程序每次给，不靠模型自己记。
- Jones & Bergen《Large Language Models Pass the Turing Test》（2025）：被判断成真人，关键在人设和说话方式（简短、口语、不完美）。→ `imperfect`、累了回短的、可以不接话。
- 《Language Model Goal Selection Differs from Humans'》（2026）：模型自己挑的目标不如人多样。→ 目标和意图的抽取由程序带随机，不让模型来挑。
- Baars 的全局工作区理论、ACT-R、SOAR、大五人格、自我决定论（自主、胜任、联结）：分区接口、意图加权和驱力种类的依据。
