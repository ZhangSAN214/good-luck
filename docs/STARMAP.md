# 星图

顶栏「星图」打开一张全屏、可以转动的立体星图。两种：

- **圆桌星图**：中心是圆桌（当前版本号）。周围七个星区：终端、办公室、公寓楼、群聊、工作台、成员、体检。
  - 每次版本更新是一颗星，按标题和内容里的关键词挂到所属部门（`core/starmap.py` 的 `DEPARTMENTS`），一周内的更新闪光圈；大功能（minor）比小改（patch）亮。
  - 每位成员是一颗星，亮度 = 她的人生星图完整度；有缺的星域时外面套一圈红色虚线。成员之间按亲近度连弧线。点两下（或卡片里的按钮）进入她的人生星图。
  - 体检（「出问题点这里」）里黄 / 红的项是缺口；最近 60 次更新都没轮到的部门也算一个缺口。
- **人生星图**：中心是成员本人，十个星域覆盖一个类人智慧生命的全部要素：
  身份、性格、三观、喜好、能力、记忆、关系、情绪、表达、成长。
  - 数据都来自已有模块：自我档案（身份 / 性格 / 三观 / 喜好 / 表达）、成长（熟练度、每周反思的改动、习惯）、记忆件（按重要度挑最多 14 件 + 挂着的事）、关系（和你、和同事）、状态（心情、精力、作息、最近的反应）。
  - 星域里一样都没有时补一颗缺口星，卡片里写怎么补。左上角是完整度（有内容的星域 / 10）。
  - **相关线**（虚线弧）：记忆里提到的喜好 / 看重的事 / 身份，和记忆同领域的能力，提到同事的记忆 ↔ 关系，成长改动 ↔ 它改的那一项设定。

## 操作

拖动转动，滚轮 / 双指缩放。点一颗星：镜头转过去，和它相连的星亮起、其余变暗；右侧卡片写详情和「相关的星」，点相关的星接着跳。左侧星区 / 缺口、底部的变化条都能点。底部时间轴拖回过去，只显示那天以前就有的星（更新、记忆、成长），「▶」从头放一遍，看圆桌和成员是怎么一路长出来的。手机上左侧目录收进右上角「星域 / 星区」按钮。

## 规则

- 只读、不调模型、不写库、不加依赖；`core/starmap.py` 是纯函数（同样的输入同样的输出，有测试），服务层 `star_map()` / `star_map_member()` 只是把已有接口的返回交给它。
- 接口：`GET /api/starmap`、`GET /api/starmap/{成员}`。
- 星图只在本机网页里看，不进任何提示词（工作模式照旧不读人设和档案）。
- 前端 `web/js/starmap.js`：canvas 2D + 自己写的透视投影（几百颗星，平板也流畅），摆位置在前端做（按 id 散列，刷新后位置不变）；系统设置了「减少动态效果」时不自动旋转。
