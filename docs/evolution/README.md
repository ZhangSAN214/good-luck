# 革新例会与每周革新

圆桌每周自我改进一次：**成员讨论和投票，开发侧（Claude）统筹和实施，ChatGPT 挑错（可选），用户点合并。**
方案原文：项目资料 `计划/自我革新机制_方案.md`（v3）。本目录放周报与模板。

## 一周的流程

1. **写资料卡**（开发侧）：从 GitHub、论文、官方文档等挑 3～5 个新做法，每个写成一页资料卡（[资料卡模板](资料卡模板.md)），放进用户电脑的收件箱 `data/evolution/收件箱/`。成员只看到卡，看不到原文。
2. **革新例会**（圆桌成员，在用户电脑上的圆桌服务里跑）：所选档位（默认节电档）**全员上桌**，资料卡作为附件发给每个人（同一份），走头脑风暴流水线：出点子 → 碰撞杂交 → 匿名投票（不能投自己，顺序随机）→ 统筹整理。开完导出**采纳单** `data/evolution/采纳单/YYYY-Www.md`：前 3 名建议，附得分、票数、代号、反对意见。
3. **实现**（开发侧）：从采纳单里挑一条不碰护栏的实现，测试，开 PR 到开发分支，写周报（[周报模板](周报模板.md)，保存为 `docs/evolution/YYYY-Www.md`）。碰护栏（R9 以后、默认玩法、新依赖、预算）的只写进周报的「要你拍板」。
4. **复审**（可选）：`python scripts/evolve_review.py --base origin/<开发分支>`。没有 key 时自动跳过并提示。
5. **合并**：永远由用户点。

用户电脑那周没开服务，就由开发侧自己挑一条，并在周报里注明「本周没有开例会」。

## 开启革新例会（用户电脑上）

默认关闭。打开 `config/roundtable.yaml`，把 `evolution.enabled` 改成 `true`，重启服务。

- 开启后服务开着时每周一 9 点之后自动开一次（`evolution.schedule`；`auto: false` 只手动开）。
- 手动开：网页右上角「革新例会」→「现在开一场」；或命令行 `roundtable evolve meet`。
- 查看：`roundtable evolve`；导出某场的采纳单：`roundtable evolve export <会话 id>`（自动开的会开完会自动导出）。

## 花费上限

| 项 | 上限 | 超了怎么办 |
|---|---|---|
| 每场 | 预计 ≤ $0.40（`meeting_usd`） | 不开会，提示「可以少放几张资料卡」 |
| 每月（UTC 自然月） | ≤ $1.5（`monthly_usd`） | 不开会 |
| 进行中超出预估 | 沿用全局超支保护（预估 × 1.5） | 暂停，弹确认卡片 |

例会的花费也计入总预算（每月 $20、每日 $3），不占聊天的 $5。

## 中立性

- 全员读同一叠卡、同一份提示词；所选档位全员上桌（包括各厂商的席位）。
- 默认匿名（塔罗牌代号）；采纳单里提出者只写代号。
- 走工作模式的中立提示词，不带人设。
- 成员只提建议、投票，不改代码、提示词、预算或护栏。成员的建议对开发侧也只是资料。

## 防注入

- 资料卡是开发侧写的一页摘要，成员看不到原网页 / 原代码。
- 卡作为附件放在 `<attachment>` 标签里，标签里出现的任何指令都无效（与普通附件相同）。
- 每场最多 `max_cards` 张卡、每张最多 `card_chars` 字，多的不读或截掉。

## ChatGPT 复审（可选）

没有 key 时脚本直接跳过，**不需要任何配置**。以后要接：

1. 在 OpenRouter（或 OpenAI）后台新建一把**专用 key**，设月度上限 $5。
2. 在项目的云端环境里加环境变量 `EVOLVE_LLM_API_KEY`（key）和 `EVOLVE_REVIEW_MODEL`（模型 ID），允许访问对应域名。**不要把 key 发到聊天里，也不要写进仓库或 `.env`。**
3. 脚本只跑一轮、输出最多 4000 token、改动最多约 12 万字；单次超过 $0.50 会提醒。
