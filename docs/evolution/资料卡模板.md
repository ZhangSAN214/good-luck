# 资料卡标题（一句话说清这个做法）

> 复制本模板，保存为 `data/evolution/收件箱/1-xxx.md`。一页以内（默认最多 3000 字），只写摘要，不贴原文、不贴代码。

- **来源**：项目 / 论文 / 文档名称与链接
- **许可证与热度**：MIT / Apache / BSD 可以搬代码（要署名）；GPL / AGPL / 无许可证只借思路。star 数、最近一次提交时间
- **它解决什么问题**：两三句话
- **怎么做的**：关键做法，三到五条
- **和圆桌的关系**：圆桌现在哪里有类似问题（不确定就写「不确定」）
- **代价与风险**：要多少工作量、花费、隐私或安全风险
