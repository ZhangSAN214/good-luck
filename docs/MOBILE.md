# 手机 / 平板上用圆桌（安卓 App、iPhone / iPad）

圆桌照旧跑在你的电脑上，数据只在电脑上；手机和平板只是「遥控器」。所以电脑要开着，并且用 **「圆桌（平板可连）」图标**（见 [DESKTOP.md](DESKTOP.md)）或 `start_lan.bat` 启动。口令、二维码、防火墙和安全设计见 [LAN.md](LAN.md)。

## 安卓：安装圆桌 App（约 5 分钟）

1. 拿到 `roundtable-android.apk`（我会直接发给你；自己拿：GitHub 仓库 → Actions → Android → 最新一次运行 → Artifacts，下载后解压）。
2. 传到手机上点开安装。第一次会提示「禁止安装未知来源应用」：按提示允许这一次（只给你用来打开 APK 的那个 App 开权限）。
3. 打开「圆桌」：
   - **家里 Wi-Fi 的地址**：电脑上圆桌顶部「平板」里列出的地址，例如 `192.168.1.23:8000`（也可以粘贴二维码里的链接，直接登录）。
   - **离家时的地址**：装了 Tailscale 才填（方案见 LAN.md 末尾，还没做），可以空着。
4. 点「连接」，输入访问口令。之后点开 App 自动连上，登录保持 30 天。

在圆桌里按手机「返回」可以回到连接页改地址。连不上时页面会提示排查步骤（电脑没开、没用「平板可连」启动、不在同一个 Wi-Fi）。

**它是什么**：一个很薄的外壳（Capacitor），里面只有连接页；连上后显示的就是电脑上的圆桌网页，所以电脑上圆桌更新了，手机上不用重装。App 只存电脑的地址和登录 cookie，关闭了云备份。只能打开家用私有地址（192.168.x、10.x、172.x、100.x）、`.local` 和 Tailscale 的 `.ts.net`，别的链接交给系统浏览器。

**更新 App**：只有连接页本身改了才需要；新 APK 直接覆盖安装（签名固定）。

**不上架应用商店**：上架 Google Play 要一次性 25 美元并公开发布，圆桌只给自己用，侧载就够了。

## iPhone / iPad：添加到主屏幕

苹果不允许随便安装 App：做成真正的 App 需要 Mac + Xcode 打包，装到自己设备上要么每 7 天重装一次（免费 Apple ID），要么付苹果开发者账号每年 99 美元。圆桌本来就靠电脑运行，原生 App 和「添加到主屏幕」能做的几乎一样，所以苹果设备用后者：

1. 在 Safari 打开电脑「平板」面板里的地址（或用相机扫二维码），输入口令。
2. 点「分享」→「添加到主屏幕」。之后从桌面图标打开，全屏显示，像 App 一样。

如果电脑的地址变了（路由器重启后可能变），桌面图标会打不开，需要重新添加。避免办法：在路由器设置里给电脑「固定 IP / 地址保留」。

## 自动打包与测试

- `.github/workflows/android.yml`：每个改了 `mobile/` 的 PR 在 GitHub 上打包 APK（不用装 Android Studio），产物在这次运行的 Artifacts 里，保留 30 天。也可以在 Actions 页面手动运行。
- 签名用仓库里的 `mobile/debug.keystore`（调试签名，口令是公开的 `android`）：只是让新版能覆盖安装，不代表任何身份。
- `tests/web/test_mobile_connect.py`：地址解析、配对链接、依次试家里 / 离家地址、连接后按返回不会又自动跳走。
