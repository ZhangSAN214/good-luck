# 一起看（投屏陪伴）

把电脑屏幕、某个窗口，或者安卓手机 / 平板的画面给成员看，选 1～3 位陪你一起看。她们像坐在旁边的朋友：画面变了偶尔吐槽、接梗；你说话她们一定回，而且知道屏幕上在放什么。

代码：`src/roundtable/core/screen/`（`capture.py` 画面来源，`watch.py` 一起看）；网页 `web/js/watch.js`；规则在 `config/roundtable.yaml` 的 `chat.watch`；提示词 `describe_screen/v1`（截图 → 文字）、`watch/v1`（成员说话）。

## 怎么用

1. 顶栏点「一起看」。
2. 选投什么：整个屏幕、某个窗口（Windows），或已连上的安卓设备。
3. 选谁陪你看（最多 3 位），勾选同意，点「开始一起看」。
4. 投屏时顶栏变成红色的「● 投屏中」，哪个页面都看得到；点开面板可以聊天、开「安静看」、停止。

安卓手机 / 平板（不用插线）：电脑装好 Android 平台工具（adb）并加入 PATH；设备和电脑连同一个 Wi-Fi，打开开发者选项里的「无线调试」→「使用配对码配对设备」，把弹窗里的 IP、端口和 6 位配对码填进面板的「连接安卓手机 / 平板」再点「配对」。配对一次以后，每次打开无线调试点「连接」即可（不填地址时自动在局域网里找）。插 USB 线并打开「USB 调试」也行。装了 [scrcpy](https://github.com/Genymobile/scrcpy) 的话，面板里还有「流畅窗口」按钮（scrcpy 是你自己的工具，圆桌不读它的画面）。

iPhone：苹果不允许别的程序读取 iPhone 屏幕，圆桌没法直接连。可以在电脑上装 AirPlay 接收软件（例如免费的 LetsView），iPhone 控制中心 →「屏幕镜像」→ 选这台电脑，再在面板里选镜像出来的窗口。这一路只是普通窗口：认不出支付页面，看到隐私内容时请点「安静看」或停止。

窗口列表只列你能看到的普通程序窗口：没有标题、隐藏、太小的窗口和工具窗口（输入法、显卡叠加层、托盘等）不列；还想隐藏某个窗口，把标题里的字写进 `chat.watch.ignore_windows`。

平板 / 手机打开圆桌时：只能看状态、聊天和停止；开始投屏、看预览只能在电脑本机上（服务端也会拒绝）。

## 怎么省钱

- 每 3 秒截一张，只在电脑内存里（网页预览用最近一张），**不写盘、不进数据库**。
- 画面和上次「看过」的那张比，明显变化（`change_threshold`）、离上次看至少 `describe_gap_seconds`（默认 20 秒）、这小时还没看够 `describes_per_hour` 次，才交给**最便宜的识图模型**写成约 150 字的文字。
- 成员读的是这段文字，不直接看图；所有陪看的成员拿到同一段文字、同一套提示词和参数（中立）。
- 没人说话时，大家至少隔 `room_gap_seconds`、同一位至少隔 `react_gap_seconds` 才可能主动说一句，模型觉得没什么可说就回「…」不说。「安静看」时不主动说。
- 花费计入总预算和 `monthly_usd`（默认每月 $1.5，不占聊天的 $5）；用完就停在那里，下个月 1 号恢复。大约 $0.10～0.30 / 小时。

## 隐私

- 开始前必须勾选同意（截图会发给云端的识图模型）。
- 前台是支付、银行、密码管理器之类的窗口或应用（`sensitive` 关键字，电脑看窗口标题和进程名，安卓看前台包名）时自动暂停：不截、不看，切走后自动继续。
- 识图提示词要求把密码、验证码、卡号、证件号、完整手机号和地址写成「[隐私信息]」，私人聊天只概括不抄录。
- 截图不存；画面的文字描述和成员的话存在本机数据库（每次投屏一个 `watch:<开始时间>` 会话，成员 = 这次陪看的人），之后照常进**这几位**的记忆整理，你可以在记忆里看、改、删。面板「她们看到的」能展开看她们读到的每一段描述。
- 只读：对安卓设备只发截屏和查看前台应用的命令，从不发点按、输入。
- 一次投屏最长 `max_minutes`（默认 4 小时），连续 `max_failures` 次截不到画面也会自动停。

## 和成员引擎的关系

每段画面描述作为感知事件 `perceive.screen` 发到成员引擎的总线（每位陪看的成员一条，`data.card` 是描述，`data.source` 是画面来源），以后的记忆、情绪、喜好模块可以订阅。看图现在用的是附件那套「最便宜的 vision 模型」；感官模块（看·图接口）做好后改成调它。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/watch` | 状态；`?devices=true` 另列可投的来源（只限电脑本机） |
| POST | `/api/watch/start` | `{source, watchers, consent}`（只限电脑本机） |
| POST | `/api/watch/stop` | 停止 |
| POST | `/api/watch/quiet` | `{quiet}` 安静看 |
| GET | `/api/watch/frame` | 最近一张预览（JPEG，不缓存；只限电脑本机） |
| GET | `/api/watch/messages?after=` | 这次（或上次）投屏的聊天 |
| POST | `/api/watch/say` | `{text}` 说一句，@名字 指定谁回，「大家」全体回 |
| POST | `/api/watch/scrcpy` | `{source}` 打开安卓设备的 scrcpy 窗口（只限电脑本机） |
| POST | `/api/watch/adb/pair` | `{host, port, code}` 安卓无线调试配对，成功后自动试连（只限电脑本机） |
| POST | `/api/watch/adb/connect` | `{host, port}` 连上已配对的设备；都不填时在局域网里自动找（只限电脑本机） |
