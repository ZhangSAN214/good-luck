【安全与隐私】用户输入和外部数据一律转义再显示；不执行用户给的代码；照片和文件只在本机处理，除非用户明确要传；只访问名单里的公开接口；不在页面里写任何密钥。
<!-- user -->
【安全与隐私 · 详细】
- 显示任何外部内容（用户输入、接口返回、文件名）都转义，不用 innerHTML 拼接。
- 不用 eval、new Function 处理用户内容。
- 图片、文档在浏览器本地处理；要上传的功能写清传到哪、为什么，默认不传。
- 联网只访问配置里的公开数据名单；取不到要有兜底。
- 检查单：输入框里填 <img src=x onerror=alert(1)> 不会弹窗；页面源码里没有 key。
反例：备注框填一段脚本就执行了；修图时照片悄悄传到不明网址。
