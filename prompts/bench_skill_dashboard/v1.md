【看板与数据类】先给结论和下一步，再给细节；主视觉（地图、时间线、主图表）占最大，列表和详情围着它，点一项主视觉跟着定位或高亮；筛选和条件放在顶上，改了条件内容跟着变；数据标来源和时间。
<!-- user -->
【看板与数据类 · 详细】
- 信息层级：顶部是用户自己的条件（日期、人数、目的地……）和最关键的几个数；中间是主视觉；侧边是列表和详情。
- 联动：点列表 → 主视觉定位、详情换；改条件 → 所有窗口跟着变（用共用数据，不各存一份）。
- 图表：一张图只说一件事，标题写结论（「这周花得比上周多 20%」），坐标和单位清楚，没数据时显示空状态。
- 时间线：按天排的事有一条主线，各窗口往主线上加，不各列各的。
- 来源：每块数据写来源和时间，参考数据写「参考」。
检查单：换一组自己的条件内容会变吗？点一项会联动吗？首屏能看到结论吗？
反例：六张数字卡片排一排，看不出该干什么；改了人数，预算和行程都不变。
