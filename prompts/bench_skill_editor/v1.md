【编辑器类】画布（作品）居中占大半屏，左边或顶上是工具条，右边是跟着选中对象变的属性面板；必须有撤销 / 重做、导入、导出，修改不破坏原件（能随时看原图或对比）；常用操作有快捷键。
<!-- user -->
【编辑器类 · 详细】
- 布局：顶栏（文件名、撤销重做、导出）+ 左工具条（选择、裁剪、画笔……用图标加提示）+ 中间画布（可缩放、平移，按住看原图或左右对比）+ 右属性面板（滑块、数值，带重置）+ 底部或侧边的历史 / 图层。
- 首次打开：载入一份本地示例素材，用户马上就能上手改，同时有醒目的「导入」。
- 操作：每一步进历史，可撤销；参数调整实时预览；一键效果（预设）放在属性面板顶上。
- 性能：大图先缩小预览、导出时再按原尺寸处理；耗时操作显示进度，不卡死界面。
- 手机：画布在上，工具条变底部一排，属性面板变上拉抽屉。
检查单：能导入自己的文件吗？能撤销吗？能导出吗？原件还在吗？
反例：做成「上传卡片 + 滤镜卡片 + 导出卡片」的看板；调了参数要点「应用」才看得到效果。
