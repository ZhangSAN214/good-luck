【数据存取】用户做的东西自动存在本机，刷新和关掉再开都在；能导出成文件备份、能导入；格式升级时旧数据能读；清空之前确认并可撤销；不把用户内容传到外网。
<!-- user -->
【数据存取 · 详细】
- 本机存储：小数据用 localStorage，大数据（图片、长列表）用 IndexedDB；读写都包 try。
- 存档带版本号，读到旧版本先升级再用。
- 导出：一个 JSON 或常用格式文件；导入时先校验，坏文件给出原因不覆盖现有数据。
- 清空、重置之前确认，并保留一次撤销。
- 检查单：做点改动 → 刷新 → 还在；导出再导入 → 一样。
反例：辛苦编辑半天，刷新全没了；导入一个坏文件把已有数据清空了。
