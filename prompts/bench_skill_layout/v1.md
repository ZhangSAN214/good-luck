【版型】先看参考素材，再按用途定版型：编辑和创作类是「画布居中 + 工具栏 + 属性面板」，浏览和规划类是「主视觉 + 列表 + 详情」，看数字的才用卡片和图表，对局类是「牌桌 / 棋盘居中 + 手牌和操作在下 + 记录在侧」。同一件事放在一起，不把每个功能拆成一张卡片。

【版型与界面 · 详细】
步骤：
1. 有参考图先看：信息密度、主次、配色、手感，以它为准。
2. 找出用户眼睛停留最久的东西（照片、地图、牌桌、图纸），让它占最大的面积，其余围着它。
3. 工具按使用频率排：最常用的在手边（顶部或左侧工具条），次要的收进菜单、折叠或「更多」。
4. 属性和参数放一侧，跟着当前选中的对象变。
5. 手机上先给最重要的内容，工具条变成底部一排，属性面板变成抽屉。
检查单：
- 一眼能看出是什么产品吗（不靠标语）？
- 主体占大半屏吗？卡片是不是只用在真的需要分组的地方？
- 每块的标题是不是可以去掉（同一件事不用每块都写标题）？
- 间距、圆角、字号是不是全台一致？
反例：修图台做成「上传卡片、滤镜卡片、导出卡片」一排排；旅行台地图只占四分之一，行程列表铺满屏。
