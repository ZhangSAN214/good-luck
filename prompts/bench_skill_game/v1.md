【游戏与模拟类】规则写成独立的状态机（回合、阶段、合法操作），界面只显示状态、发出操作；随机用可复现的种子；能存档、读档、重开；对手或主持由程序或 ctx.askJson 驱动；涉及金钱一律用模拟数据并写明「模拟」。
<!-- user -->
【游戏与模拟类 · 详细】
- 布局：牌桌 / 棋盘 / 场景居中，玩家自己的手牌和操作在下，对手和记录在两侧，回合提示醒目。
- 规则：先把规则写成数据和纯函数（谁的回合、能做什么、怎么结算），每个操作先判断合不合法；不合法时说明原因。
- 进度：每一步记日志（能回看），能悔一步（练习模式）、存档读档、重开一局。
- 对手：简单的规则型对手先走通；需要语言的角色（主持、NPC）用 ctx.askJson，按规则限定它能做的事。
- 模拟经营 / 金融：只用模拟或历史数据，标明「模拟」，不接真钱、不给投资建议；账本、收益曲线要算对。
检查单：从开局到结算能完整走一遍吗？非法操作会被拦下吗？刷新后能接着玩吗？
反例：界面画得像麻将桌，其实点牌没有任何规则判断；炒股台的「实时行情」是编的随机数却不写「模拟」。
